# AI Network Research

这是一个网络流量异常检测的学习与研究仓库。目前以 UNSW-NB15 数据集为起点，学习网络流量的基本概念、梳理数据集，并探索一个问题：模型在随机划分数据上取得的高准确率，遇到时间或场景变化时是否仍然可靠？

## 目前的认识

- 数据包是网络传输的基本单位；网络流由具有共同特征的数据包组成，通常可用源/目的 IP、源/目的端口和协议组成的五元组识别。
- UNSW-NB15 的记录描述网络流及其连接行为，提供正常/攻击二分类标签 `label` 和攻击类别 `attack_cat`。预测 `label` 时不能把 `attack_cat` 当作输入特征，以免泄露答案。
- 已在 [探索笔记](notebooks/01_explore_unsw_nb15.ipynb) 中读取预定义训练集：共 175,341 条记录、45 列，其中攻击流量 119,341 条，正常流量 56,000 条。这是训练集的分布，不代表完整数据集的分布。
- 根据 [论文阅读笔记](notes/papers/unsw_nb15_2015.md)，该数据集来自受控环境，攻击类别分布不均；相邻流量及连接统计特征可能存在关联。因此，随机划分的结果需要结合更严格的划分方式与分类指标审视。这仍是后续要验证的研究问题。
